O projeto fio-condutor

Todas as aulas constroem incrementalmente o UniEventos, uma plataforma de divulgação e inscrição em eventos acadêmicos. O professor desenvolve o UniEventos em sala; cada estudante desenvolve um projeto autoral com a mesma arquitetura e domínio diferente. As avaliações são sobre o projeto autoral.

Como usar este material

  • Cada aula tem objetivos, teoria, passo a passo prático, laboratório em sala, tabela de erros comuns e uma atividade assíncrona de 1 hora.
  • Todos os blocos de código têm botão Copiar.
  • Atalhos de teclado: j próxima aula, k aula anterior, / busca.
  • Use o botão Tema para alternar entre claro e escuro. A impressão (Ctrl+P) gera um PDF limpo.
